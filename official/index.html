手動新增 KGEN 到錢包

適用 MetaMask、Trust Wallet 與 OKX Wallet。手動新增只讓錢包顯示這個代幣，不會取得或兌換 KGEN。請在錢包官方 App 或官方擴充套件內操作；新增顯示不需連接本網站、不需簽名或發送交易，也不需輸入助記詞或私鑰。

先選 BNB Smart Chain（BEP-20），使用上方完整官方合約地址：若錢包支援合約地址搜尋，可直接貼上整串地址並核對搜尋結果；找不到正確結果時，複製整串地址，依下方步驟新增／匯入自訂代幣。不要只憑幣名或符號辨認代幣。

匯入只讓錢包顯示該資產及其餘額，不會轉帳、不會買幣，也不代表錢包官方收錄或交易所上架。各錢包版本的搜尋及顯示方式可能不同，請核對完整合約地址。

MetaMask

  1. 先選擇錢包內既有的 BNB Smart Chain 網路。
  2. 手機：展開 Tokens → ＋ → Custom token。擴充套件：Tokens 區 ⋮ → Manage tokens → Add custom token。
  3. 貼上本頁合約地址，選 Next，再選 Import。如有顯示名稱、符號或小數位，請與上方資料核對。

MetaMask 官方新增代幣說明

Trust Wallet

  1. 進入代幣管理：手機可由首頁 ＋ 進入；部分版本為資產版面 → Manage crypto。擴充套件可在首頁底部選 Manage crypto。
  2. 選 ＋ 新增自訂代幣，網路選 BNB Smart Chain。
  3. 貼上本頁合約地址；若需填寫其他欄位，名稱填 KLINE GENESIS、符號 KGEN、小數位 18。核對後選 Import。

Trust Wallet 官方新增代幣說明

OKX Wallet

  1. 使用 OKX Wallet；若是整合版 OKX App，先切換到 Web3 錢包。
  2. 手機：Crypto → Manage crypto → Custom crypto。擴充套件：往下捲至 Manage crypto → Custom crypto。
  3. 選既有 BNB Chain 網路並貼上本頁合約地址，核對後選 Confirm。若有顯示其他代幣資料，請與上方資料核對。

新增顯示、兌換與行情

手動新增代幣與 PancakeSwap 外站兌換是不同操作。若要在外站查看 BNB → KGEN，請先確認網路為 BNB Smart Chain，再選 BNB 作為輸入代幣，並核對輸出代幣的完整 KGEN 合約地址。下方沿用官網既有兌換連結，連結本身不代表已鎖定網路或讀到即時報價。
