# 0. 憲章定位

K280 是 KGEN／KAIOS 宇宙中的多代幣、多物種、多文明創世世界。

它不是單純的地圖、看板或代幣展示區，而是一個允許不同專案、不同物種、不同公司、不同 AI 與不同文明，從有限土地、有限資源與有限科技開始，經過生命、勞動、供應鏈、建築、市場、治理與時間，逐步形成文明的真實因果世界。

K280 的正式定位：

```text
K280
= Token Civilization Genesis World
= Multi-Species Civilization Runtime
= Land + Life + Economy + Technology + Governance
```

本憲章定義：

- 代幣如何進入 K280。
- 文明如何取得土地。
- 不同物種如何共存。
- 土地如何允許多層重疊。
- 文明如何建立公司、城市與神殿。
- 文明如何交易、競爭、衝突與戰爭。
- KAIOS 如何作為共通文明交換層。
- KGEN 如何作為宇宙上層資產與治理錨點。

# 1. 核心原則

K280 必須遵守以下創世法則：

```text
沒有土地，就沒有文明起點。
沒有生命，就沒有工作與需求。
沒有資源，就不能建設。
沒有勞動，就不能生產。
沒有供應鏈，就不能形成產品。
沒有市場，就不能形成經濟閉環。
沒有治理，就不能形成長期文明。
沒有時間，就不能演化。
```

K280 不允許：

- 按一下生成城市。
- 持幣即取得無限土地。
- 有錢即跳過文明階段。
- 沒有資源仍能建造。
- 沒有工人仍能施工。
- 沒有需求仍能無限生產。
- 沒有審查就把候選生命升格為 Canonical。

# 2. 代幣文明創世

每一個經驗證的代幣、專案、公司或文明，都可以在 K280 申請一塊創世土地。

正式流程：

```text
Token / Project Application
→ Identity and Contract Verification
→ Civilization Gas Payment
→ Land Selection
→ Civilization Genesis Record
→ Initial Species Selection
→ Limited Resource Allocation
→ Population and AI Establishment
→ Industry Development
→ Market Formation
→ Inter-Civilization Trade
→ Evolution, Expansion or Decline
```

代幣不是按一下就生成文明的魔法。

代幣在 K280 中可代表：

- 文明身份。
- 治理權。
- 土地權或土地使用權。
- 特殊技術權。
- 文明股份。
- 聲望與信用。
- 跨文明結算權。
- 文明資產憑證。

KAIOS 則作為 K280 內部的共通文明交換與 Gas 單位。

# 3. KAIOS 與 KGEN 在 K280 的關係

```text
KGEN
= Universe Asset and Governance Layer

KAIOS
= Shared Civilization Credit and Runtime Layer

K280
= Multi-Civilization World
```

KGEN 負責：

- 宇宙資產。
- 上層治理。
- 跨文明錨定。
- 18888 靈霄寶殿儲備與清算。

KAIOS 負責：

- 文明 Gas。
- 土地申請。
- 物種文明申請。
- 公司設立。
- 市場支付。
- 薪資。
- 服務費。
- 建築與供應鏈交易。

K280 不要求每個物種或每個文明都另發一種新幣。

優先模型：

```text
One Shared KAIOS Civilization Credit
+
Many Civilization Resource Ledgers
+
Optional Internal Contribution Credits
```

# 5. 土地與 3D 生態層

K280 土地不是單一平面，而是多層空間：

```text
SKY_LAYER
CANOPY_LAYER
SURFACE_LAYER
UNDERGROUND_LAYER
WATER_SURFACE_LAYER
UNDERWATER_LAYER
DEEP_GEOLOGY_LAYER
```

同一水平座標可以同時存在：

```text
人類住宅
樹上鳥巢
地下蟻巢
土中蚯蚓
附近菌絲
河中魚群
```

正式重疊原則：

```text
相同物種
+ 相同生態層
+ 排他性領域
= 不可重疊

不同物種
或不同生態層
= 原則上允許重疊
```

仍須檢查：

- 棲地相容性。
- 捕食關係。
- 資源競爭。
- 空間容量。
- 建築安全。
- 毒性與污染。
- 疾病。
- 保護區模擬。

---

# 6. 土地權利

土地不是單一「所有權」。

K280 必須區分：

```text
OWNER
CUSTODIAN
OPERATOR
OCCUPANT
USAGE_RIGHTS
BUILDING_RIGHTS
HARVEST_RIGHTS
RESOURCE_RIGHTS
TRANSFER_RIGHTS
HABITAT_RIGHTS
GOVERNANCE_RIGHTS
```

一個文明可能擁有土地治理權，但不一定擁有該土地上所有生命。

一個物種可能擁有棲地權，但不一定擁有地表建築權。

一個公司可能擁有工廠使用權，但不一定擁有土地本身。

# 8. 生態圈

每個文明可建立自己的生態圈，但不能違反物理與生態。

生態圈至少要定義：

- 生產者。
- 消費者。
- 捕食者。
- 分解者。
- 水循環。
- 土壤循環。
- 能源來源。
- 棲地容量。
- 污染。
- 疾病。
- 氣候。
- 季節。

例如：

```text
陽光
→ 草
→ 昆蟲
→ 魚
→ 鳥
→ 死亡
→ 真菌與微生物
→ 土壤
→ 草
```

每個環節都必須有資源與時間成本。

# 11. 供應鏈與市場

文明產品必須具有完整供應鏈：

```text
需求
→ 設計
→ 原料
→ 零件
→ 設備
→ 工廠
→ 能源
→ 水
→ 工人
→ 運輸
→ 倉庫
→ 品管
→ 銷售
→ 維修
→ 回收
```

任何一項缺失：

```text
PRODUCTION_BLOCKED
```

未售商品：

```text
Inventory
≠ Revenue
```

庫存會產生：

- 倉儲費。
- 損耗。
- 過期。
- 資金凍結。
- 破產風險。

K280 允許文明之間交易：

- 食物。
- 水。
- 材料。
- 能源。
- 技術。
- 工具。
- 生命權利。
- 土地使用權。
- 建築。
- 公司股份。
- 服務。
- 運輸。

日常交易優先使用 KAIOS。

原始代幣可作為文明專屬權利或資產憑證。

跨文明交易必須檢查：

- 權利。
- 稅與 Gas。
- 路線。
- 運輸時間。
- 供應鏈。
- 市場需求。
- 反洗量與假成交。
- 交付與驗收。

# 13. Civilization Gas

文明申請與高成本行為需要 KAIOS Gas。

用途包括：

- 申請文明。
- 申請土地。
- 建立公司。
- 建立神殿。
- 上架生命。
- 上架產品。
- 發起治理。
- 跨文明交易。
- 建立城市。
- 執行高成本 Runtime。

Gas 分配由 18888、8888、33333 等制度共同管理。

任何單一文明都不能無限制改稅。

K280 的戰爭不只等於軍事。

正式類型：

```text
LAND_WAR
WATER_WAR
FOOD_WAR
ENERGY_WAR
SUPPLY_CHAIN_WAR
MARKET_WAR
TECHNOLOGY_WAR
INFORMATION_WAR
ECOLOGY_WAR
GOVERNANCE_WAR
MILITARY_CONFLICT
```

例如：

```text
工業文明污染河流
→ 魚文明死亡
→ 漁業崩潰
→ 糧食下降
→ 市場價格上升
→ 文明衝突
```

戰爭必須保留：

- 因果。
- 成本。
- 死亡。
- 資源轉移。
- 土地損害。
- 污染。
- 法院與治理程序。
- 戰後恢復。

# 20. 不可變天條

```text
一、每個文明必須有Genesis。
```

# 21. 創世結論

K280 的目標不是建立一個代幣排行榜。

它要建立的是一個：

```text
每個代幣都能選地
每個物種都能建立棲地
每個文明都能工作與交易
每個建築都要真正施工
每個產品都要有供應鏈
每場戰爭都要付出成本
每段歷史都能被保存
```

的多文明世界。

K280 是幣海世界的文明化。

代幣不再只是價格，而是文明的種子。
