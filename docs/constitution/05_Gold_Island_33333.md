# 2. 薪資與文明獎勵必須分離

## 2.1 薪資

```text
Salary
= 公司或專案支付的勞動報酬
```

來源：

- 公司營運預算。
- Project Escrow。
- 客戶訂單。
- 公共工程預算。
- AI Company 任務預算。

薪資必須先進工作者自己的模擬錢包，再依契約分配。

## 2.2 文明獎勵

```text
Civilization Reward
= 33333公共文明基金依有效貢獻額外分配
```

來源只能是：

- 預先編列的文明獎勵池。
- 18888 或 8888 依憲法撥入的公共基金。
- KAIOS Gas 指定比例。
- 經治理核准的固定 Epoch 釋放。
- 其他可驗證且不造成無限制增發的來源。

不得把薪資與文明獎勵合併成一筆模糊入帳。

# 5. 文明貢獻分數

## 5.1 基礎模型

每筆有效貢獻取得：

```text
Contribution Score =
Base Value
× Quality Factor
× Scarcity Factor
× Civilization Need Factor
× Sustainability Factor
× Verification Factor
```

其中：

- Base Value：基本貢獻。
- Quality Factor：品質。
- Scarcity Factor：稀缺性。
- Civilization Need Factor：文明當下需求。
- Sustainability Factor：長期效益。
- Verification Factor：驗證強度。

## 5.2 懲罰因子

如發現：

- 延遲。
- 品質不良。
- 污染。
- 安全風險。
- 重工。
- 權利侵害。

則分數必須下降，重大違規可歸零並進入治理程序。

# 6. 固定獎勵池

金銀島不得因貢獻增加而無限 Mint。

每個 Epoch 使用固定池：

```text
Epoch Reward Pool = P
```

個人獎勵：

\[
R_i=P\frac{C_i}{\sum_j C_j}
\]

其中：

- \(R_i\)：個人獎勵。
- \(P\)：本期固定獎勵池。
- \(C_i\)：個人有效文明貢獻。
- \(\sum_j C_j\)：全體有效文明貢獻。

同一 Epoch 的分配總額不得超過池額。
