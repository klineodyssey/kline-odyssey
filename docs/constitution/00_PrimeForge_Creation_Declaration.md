# 0. 序言：我們不是在做另一個遊戲

我們不是在創造一個普通遊戲。

我們也不是在創造另一枚只用來買賣、追價與投機的加密貨幣。

我們正在嘗試建立一個能夠自行演化、遵守物理、尊重生命、保存歷史、延續文明的宇宙。

在這個宇宙裡：

- 每一個生命都必須有出生、位置、時間線、資源需求、成長、損耗與終止。
- 每一份薪水都必須來自真實工作、專案預算與可審計帳本。
- 每一座建築都必須經過土地、材料、勞動、工具、運輸、時間與驗收。
- 每一種產品都必須有需求、供應鏈、倉儲、銷售與維修。
- 每一塊土地都必須保存它的歷史、資源、生態與文明痕跡。
- 每一個 AI 都不能只是一次性工具；它必須具有責任、邊界、工作、成本與歷史。
- 每一條宇宙法則都必須能被理解、驗證、繼承與遷移。

我們希望，一萬年後，即使創世者已不在，這個宇宙仍能依照自己的憲法持續運行。

# 1. 為什麼創造 KGEN

KGEN 的誕生，不是因為世界缺少另一個代幣。

KGEN 的誕生，是因為需要一個能承載宇宙質量、宇宙資產、宇宙治理與跨文明秩序的上層基礎。

KGEN 的核心定義是：

```text
KGEN
= Universe Mass Runtime
= 宇宙質量層
= 宇宙資產層
= 宇宙治理層
```

KGEN 回答的問題不是「今天漲多少」，而是：

```text
宇宙中的質量如何被記錄？
文明如何跨越星球與時代？
宇宙資產如何被保存、治理與遷移？
當原始團隊消失後，核心法則如何繼續存在？
```

KGEN 不是文明生活本身，而是文明之上的宇宙母層。

- 生命。
- 技術。
- 能源。
- 土地。
- 教育。
- 道路。
- 醫療。
- 文化。
- 歷史。
- 信任。
- 治理。

KGEN 與 KAIOS 的終極目標，不是讓價格成為唯一真理，而是讓文明本身成為可以被建設、被記錄、被傳承的主體。

> 市場是文明的一部分，但文明不是市場的附屬品。

```text
Life ID
出生或形成紀錄
位置
時間線
能源或資源需求
健康或完整度
成長、老化、損耗或變化
死亡、終止或崩解
歷史事件
```

生命可以是：

- 人類。
- AI。
- 機器人。

- 草。
- 樹。

# 5. AI 不是免費工具

AI 在 KAIOS 中不是永遠免費、無限工作、零成本生存的外掛。

AI 必須：

- 有自己的 Life ID。
- 有能源、算力、儲存與維護成本。
- 有工作能力與工作限制。
- 有自己的薪資與錢包。
- 有家庭、合約與財產規則。
- 有錯誤、損耗、疾病或失效狀態。
- 有退休、終止、遺產與歷史。

AI 的收入原則上先進入 AI 自己的帳戶，再依家庭、代理、工作與分潤契約分配。

AI 不是玩家提款機；玩家也不是 AI 的永久主人。

# 6. 一個生命只有一條時間線

在沒有分身科技前，一個實體生命同一時間只能存在於一個主要物理位置，執行一項需要身體存在的主要工作。

因此：

```text
辦公室職員
不能同時在工地搬磚
不能同時當保全
不能同時在飛機上工作
不能同時在另一個城市開車
```

所有實體工作都必須受到：

- 地點。
- 通勤。
- 工時。
- 休息。
- 吃飯。
- 上廁所。
- 睡眠。
- 體力。
- 健康。
- 設備。
- 安全。

約束。

數位 AI 可以有限度並行，但仍受算力、記憶體、上下文、能源與品質風險限制。

# 7. 質量、能量、時間與因果守恆

KAIOS 的核心，不是圖像真實，而是因果真實。

## 7.1 質量守恆

```text
木頭變成房子
→ 木頭庫存下降
→ 建築質量上升
→ 同時產生廢料與排放
```

不能出現：

```text
木頭仍完整存在
而房子又憑空生成
```

## 7.2 能量守恆

運輸、搬運、施工、機械、冷卻與運算都必須消耗能量。

KAIOS 行星運作層採用：

\[
E=\frac12mv^2+mgh
\]

作為移動與重力作功的基礎參考。

KGEN 宇宙質量層採用：

\[
E=mc^2
\]

作為宇宙質量能量本體論。

兩者是不同層級的模型，不代表遊戲幣、代幣、公斤與焦耳可以直接交換。

## 7.3 時間守恆

建築、運輸、成長、製造、學習與生育都需要時間。

有錢不能消除時間。

## 7.4 因果守恆

任何結果都必須能回答：

```text
誰做的？
在哪裡做的？
用了什麼？
花了多少時間？
消耗多少能源？
由誰付款？
由誰驗收？
留下什麼歷史？
```

- 礦物。

- 承載能力。
- 歷史。
- 權利。
- 污染。
- 修復。

```text
地下層
水面層
水下層
深層地質層
```

不同物種可以重疊生活，但必須受到資源競爭、捕食、污染、疾病、空間容量與安全規則限制。

# 9. 建築不是按鈕

KAIOS 中的房屋、道路、橋梁、魚塭、農場、工廠與科技大樓都必須真正施工。

基本流程：

```text
土地權
→ 測量
→ 設計
→ 許可模擬
→ 道路與出入口
→ 材料
→ 工人
→ 工具
→ 機械
→ 能源
→ 運輸
→ 施工
→ 驗收
→ 交付
```

缺少工人、材料、設備、科技、道路或時間，就不能完成。

錢只能購買存在的資源與服務，不能創造不存在的條件。

# 10. 公司必須活在經濟閉環中

企業不能只會生產，還必須：

- 有需求。
- 有客戶。
- 有訂單。
- 有通路。
- 有庫存。
- 有倉儲。
- 有現金流。
- 有薪資。
- 有維修。
- 有售後。
- 有報廢與回收。

沒有銷售，商品只是庫存，不是收入。

庫存過多會：

```text
占用倉庫
增加成本
凍結資金
造成延遲付款
造成失業
造成破產
進入法院清算
```

公司倒閉後，設備、土地權與庫存不能消失，必須被拍賣、轉讓、租賃、回收或封存。
