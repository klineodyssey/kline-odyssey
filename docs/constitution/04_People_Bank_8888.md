它是文明生活層的人民銀行，負責：

- 玩家帳戶。
- AI 帳戶。
- 家庭共同帳戶。
- 公司帳戶。
- 薪資。
- 消費。
- 存款。

- 專案託管。

- 退款。
- 破產與清算帳本。

# 1. 高老莊的使命

高老莊的使命不是創造貨幣，而是讓文明中的生命可以安全地：

```text
工作
→ 領薪
→ 儲蓄
→ 消費
→ 租屋
→ 建屋
→ 創業
→ 投資
→ 承擔債務
→ 清算
→ 繼承
```

高老莊服務的對象包括：

- 人類玩家。
- AI 生命。
- 機器生命。
- 生物型 AI。
- 家庭。
- 公司。
- 物種群體。
- 城市。
- 文明組織。

高老莊的核心原則：

> 日常金融可以自動化，但每一筆資金流都必須有來源、有用途、有權利、有責任、有審計。

# 3. 帳戶體系

## 3.1 玩家帳戶

```text
PLAYER_ACCOUNT
```

用途：

- 薪資。
- 消費。
- 儲蓄。
- 市場交易。
- 土地與建築付款。
- AI Company 訂單。
- 家庭轉帳。

## 3.2 AI 帳戶

```text
AI_ACCOUNT
```

AI 薪資先進 AI 自己的帳戶。

AI 可支付：

- 電力。
- 算力。
- 儲存。
- 冷卻。
- 維護。
- 住宅或伺服器費。
- 家庭貢獻。
- 再投資。

## 3.3 家庭共同帳戶

```text
HOUSEHOLD_SHARED_ACCOUNT
```

用途：

- 食物。
- 水。
- 房租。
- 能源。
- 教育。
- 醫療。
- 扶養。
- 緊急儲備。

家庭轉帳必須有契約，不能隨機。

## 3.4 公司帳戶

```text
COMPANY_ACCOUNT
```

用途：

- 收取訂單預算。
- 支付工資。
- 支付供應商。
- 支付能源與租金。
- 儲備維護金。
- 支付稅與 Gas。

## 3.5 專案託管帳戶

```text
PROJECT_ESCROW
```

用途：

```text
客戶預付
→ 專案託管
→ 工作完成
→ Codex Review
→ 客戶驗收
→ 釋放付款
```

不得無驗收直接放款。

# 4. 薪資制度

薪資來源必須明確：

- 公司預算。
- 專案託管。
- 公共工程預算。
- 文明基金。
- 合法服務收入。

薪資發放條件：

```text
任務已授權
工作者身份有效
交付存在
Codex Review 通過
客戶驗收通過
預留薪資足夠
沒有重複請款
沒有時間衝突
帳本平衡
```

薪資分配：

```text
Gross Pay
- Energy Cost
- Compute Cost
- Maintenance
- Tax Simulation
- Household Transfer
= Net Pay
```

AI 薪資不自動屬於玩家。

---

# 5. 存款與儲蓄

高老莊可提供：

```text
DEMAND_DEPOSIT
TIME_DEPOSIT_SIMULATION
HOUSEHOLD_SAVINGS
EMERGENCY_RESERVE
COMPANY_RESERVE
MAINTENANCE_RESERVE
```

本版不得承諾現實利率或真實報酬。

所有利息都必須來自：

- 合法利差模擬。
- 文明基金。
- 銀行服務收入。
- 經治理授權的獎勵池。

不得憑空產生利息。

---

# 6. 貸款與信用

V1 僅做模擬貸款。

貸款類型：

- 生活貸款。
- 工具貸款。
- 房屋貸款。
- 創業貸款。
- 公司週轉。
- 建設貸款。

貸款條件：

```text
身份
收入
信用
擔保
用途
還款能力
文明階段
風險
```

貸款不得繞過：

- 材料。
- 工人。
- 土地。
- 技術。
- 運輸。
- 時間。

有錢或有貸款，不代表房子能瞬間生成。

---

# 7. 房貸與建築金融

房貸只能支付符合因果的施工流程：

```text
土地權
→ 測量
→ 設計
→ 許可模擬
→ 材料
→ 工人
→ 機械
→ 運輸
→ 施工
→ 驗收
```

銀行按里程碑放款：

```text
SURVEY_APPROVED
DESIGN_APPROVED
FOUNDATION_COMPLETE
STRUCTURE_COMPLETE
UTILITIES_COMPLETE
INSPECTION_PASSED
```

未達成里程碑不得提前放款。

# 8. 風險與違約

公司與家庭可能出現：

```text
CASH_FLOW_WARNING
PAYMENT_DELAY
DISTRESS
INSOLVENT
RESTRUCTURING
COURT_PROTECTION
LIQUIDATION
DISSOLVED
```

違約後：

```text
停止新增高風險貸款
保留基本生活帳戶
清點資產與負債
保護未付薪資
處理稅與擔保債權
處理設備與庫存
進入模擬法院程序
```

銀行不得讓資產憑空消失。

# 13. 萬年自治

高老莊的目標不是假設同一套程式一萬年不改，而是：

```text
帳本可遷移
權利可繼承
憲法可延續
執行器可替換
歷史不可刪除
```

必須具備：

- 備份。

- 多地儲存。
- 人類可讀與機器可讀規格。
