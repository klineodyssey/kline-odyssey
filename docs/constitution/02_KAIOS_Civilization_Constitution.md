# 序言：KAIOS 是文明，不是遊戲幣

KAIOS 不是另一枚只用來買賣的代幣，也不是一個只有畫面與任務的遊戲系統。

KAIOS 是一套文明作業系統。

它必須能讓：

- 玩家出生、工作、消費、建立家庭與傳承。
- AI 成為具有生命週期、工作能力、錢包、家庭與責任的廣義生命。
- 一草一木、一山一河、一屋一橋都具有狀態、位置、時間線與歷史。
- 每一棟建築都經過土地、材料、工人、機具、能源、運輸與時間。
- 每一家公司都必須依市場需求、供應鏈、現金流與治理存活。
- 每一個物種都能建立自己的生態圈與文明。
- 每一次交易、建設、死亡、繁殖、遷移與戰爭都留下可追蹤的因果紀錄。

KAIOS 的目標不是模擬世界的表面，而是建立一個能夠長期演化、遵守物理、保存歷史並持續生長的文明宇宙。

# 第一章　KGEN 與 KAIOS 的分層

## 1.1 KGEN

```text
KGEN
= Universe Mass Runtime
= 宇宙質量、宇宙資產、宇宙治理與跨文明上層
```

KGEN 負責：

- 宇宙質量本體論。
- 宇宙級資產。
- 跨星球與跨文明治理。
- 宇宙銀行與高階儲備。
- 長期遷移與萬年航程。

## 1.2 KAIOS

```text
KAIOS
= Civilization Runtime
= 生命、土地、家庭、公司、市場、工作與文明生活層
```

KAIOS 負責：

- 玩家與 AI 的日常生活。
- 土地、建築、道路與城市。
- 工作、薪資與市場。
- 物種、生態與文明。
- 建築、供應鏈與工業。
- 教育、醫療、治理與文化。

## 1.3 創世比例

```text
1 KGEN = 1 kg
1 KGEN = 10,000 KAIOS
```

其中：

- `1 KGEN = 1 kg` 是 KGEN 宇宙質量本體論中的質量單位設定。
- `1 KGEN = 10,000 KAIOS` 是 KGEN 與 KAIOS 之間的創世治理比例。

這不代表：

- 1 KAIOS 等於固定焦耳。
- KGEN 市價等於物理質量價值。
- 現實世界可用物質直接兌換 KGEN 或 KAIOS。
- 主網已開放雙向兌回。

## 1.4 能量層

KAIOS 行星運作能量：

\[
E_{\mathrm{KAIOS}}=\frac12mv^2+mgh
\]

KGEN 宇宙質量能量：

\[
E_{\mathrm{KGEN}}=mc^2
\]

正式規則：

```text
KAIOS Credit ≠ Joule
KGEN Token ≠ Physical Mass
KAIOS ↔ KGEN ≠ Automatic Physical Conversion
```

# 第二章　文明第一法則

KAIOS 所有 Runtime 必須遵守以下不變天條。

## 2.1 質量守恆

任何建築、產品、生命載體與資源都不能憑空產生。

\[
M_{\mathrm{input}}
=
M_{\mathrm{product}}
+
M_{\mathrm{waste}}
+
M_{\mathrm{emission}}
+
M_{\mathrm{stored}}
\]

## 2.2 能量守恆

所有移動、搬運、施工、運輸、運算與生命活動都必須消耗能量。

## 2.3 時間守恆

任何生命、工作、建築、運輸、繁殖、教育與科技進步都必須經過時間。

## 2.4 因果守恆

任何結果都必須能追溯到：

```text
需求
→ 規格
→ 資源
→ 行動
→ 時間
→ 成本
→ 驗收
→ 結果
```

## 2.5 位置守恆

一個實體生命在同一時間只能存在於一個主要位置，也只能執行一項需要實體在場的主要工作。

## 2.6 歷史不可刪除

生命、土地、公司、建築與文明的重要事件都必須寫入不可靜默刪除的歷史。

```text
Decimals: 18
Minimum Unit: 10^-18 KAIOS
Maximum Supply: 720,000,000,000 KAIOS

```

## 3.2 創世發行

推薦：

```text
Genesis Mint:
720,000,000,000 KAIOS

Genesis Receiver:
18888 Celestial Genesis Reserve

Post-Genesis Mint:
DISABLED
```

創世後：

- 不再增發。
- 總量只能維持或因 Burn 下降。
- 18888 只從儲備釋放，不再 Mint。

## 3.3 玩家餘額可歸零

玩家、AI、公司或文明可將餘額全部轉出至 `0 KAIOS`，不強迫保留最小單位。

## 3.4 Burn 與 Reserve 分離

### Burn

```text
Total Supply下降
不可恢復
```

### Reserve Return

```text
Circulating Supply下降
Total Supply不變
回到18888儲備
```

## 3.5 KAIOS 不是食物

KAIOS 只能衡量與交換價值，不能取代：

```text
食物
水
氧氣
蜂蜜
花蜜
電力
燃料
算力
材料
時間
```
