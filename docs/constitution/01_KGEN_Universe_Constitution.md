KGEN 不是普通代幣，也不是單一遊戲資產。KGEN 是宇宙質量、宇宙位置、宇宙資產、宇宙治理與跨文明秩序的上層基準。

```text
KGEN
= Universe Mass Runtime

= 跨文明秩序層
```

# 3. KGEN 質量本體論

KGEN 採用創世定義：

```text
1 KGEN = 1 metric ton = 1,000 kg
```

此定義是宇宙質量單位的治理與本體論設定，用來描述：

- 宇宙資產權重。
- 文明質量。
- 跨星球資源映射。
- 宇宙銀行儲備。
- KAIOS 創世比例。

它不表示：

- 任何人可用 1 KGEN 兌換現實世界 1 公斤物質。
- KGEN 代幣價格等於公斤市場價格。
- 錢包餘額等於真實質量持有權。

# 4. 宇宙能量模型

KGEN 宇宙層參考：

\[
E_{KGEN}=mc^2
\]

此式用於宇宙質量能量本體論，而非日常文明交易。

適用領域：

- 恆星。
- 黑洞。
- 高能宇宙事件。
- 宇宙文明等級。
- 未來跨星際能源分類。

KAIOS 行星文明層則使用：

\[
E_{KAIOS}=\frac12mv^2+mgh
\]

兩者分層：

```text
KGEN
= 宇宙質量能量

KAIOS
= 行星文明作功能量
```

不得直接將 KGEN Token 餘額換算成焦耳或真實質量。

# 5. 宇宙質量守恆

宇宙中所有文明建設、物種演化、資源採集、工業生產與星際航行，都必須保存質量與能量流向。

```text
輸入質量
=
產品質量
+
廢料
+
排放
+
儲存
+
轉移
```

任何 Runtime 不得讓：


```text

→ 房屋質量增加
→ 廢料與排放增加
```
