# 0. 憲章定位

本憲章定義 KAIOS 世界中，生命、家庭、公司、物種、城市、國家與星球文明如何從原始狀態逐步演化。

文明不能靠金錢、按鈕或管理員命令瞬間升級。

文明必須經過：

```text
人口
能源
食物
教育
工具
材料
道路
制度
市場
科技
治理
生態承載
時間
```

任何文明級別都必須有可驗證的前置條件、實際產能、供應鏈、社會組織與維持成本。

---

# 1. 文明不是裝飾

文明不是一個 UI 標籤，也不是玩家帳號上的等級數字。

文明是一套持續運作的共同生活系統。

它必須能回答：

- 生命如何取得食物與水？
- 人口如何出生、學習、工作、老化與死亡？
- 能源如何產生、輸送、儲存與維護？
- 土地如何使用？
- 商品如何生產？
- 工人如何領薪？
- 公司如何盈利、虧損、破產與清算？
- 技術如何被研究、保存與傳承？
- 社會如何處理衝突？
- 生態如何避免被文明自身摧毀？

只有當這些系統形成閉環，文明才算真正存在。


每一級都不是取代上一級，而是在上一級基礎上增加更高的能量密度、資訊密度、組織能力與文明責任。

# 3. 文明門檻模型

文明升級必須同時通過多維門檻。

## 3.1 必要門檻

```text
POPULATION_GATE
FOOD_GATE
WATER_GATE
ENERGY_GATE
TECHNOLOGY_GATE
EDUCATION_GATE
INFRASTRUCTURE_GATE
SUPPLY_CHAIN_GATE
ECONOMY_GATE
GOVERNANCE_GATE
HEALTH_GATE
ECOLOGY_GATE
SECURITY_GATE
HISTORY_GATE
```

## 3.2 升級判定

文明升級不得只靠單一指標。

示意：

```text
文明等級可升級
= 所有必要門檻通過
+ 至少維持一個完整Epoch
+ 無重大未解決崩潰風險
+ 經治理與審計確認
```

## 3.3 不能跳級

禁止：

```text
原始採集文明
→ 直接建立2奈米晶圓廠

農業文明
→ 直接使用星際艦隊

沒有道路
→ 直接形成現代物流

沒有教育
→ 直接出現大量工程師
```

# 9. 工業文明

## 9.1 核心能力

- 礦業。
- 鋼鐵。
- 水泥。
- 機械。
- 工廠。
- 卡車。
- 鐵路。
- 大型電力。
- 標準化零件。

## 9.2 工業不是自動產能

文明達到工業級，只代表具備工業可能性。

真正產品仍需完整供應鏈。

例如汽車：

```text
市場需求
→ 設計
→ 鋼鐵
→ 橡膠
→ 玻璃
→ 電力
→ 零件
→ 工廠
→ 工人
→ 組裝
→ 品管
→ 運輸
→ 銷售
→ 維修
```

缺一項即可：

```text
PRODUCTION_BLOCKED
```

## 9.3 庫存與破產

生產不等於收入。

```text
過量生產
→ 庫存增加
→ 倉儲成本
→ 現金被凍結
→ 無法支付工資
→ 違約
→ 破產
→ 法院清算
```

# 17. 文明倒退與崩潰

文明可以升級，也可以倒退。

可能原因：

- 能源中斷。
- 糧食崩潰。
- 戰爭。
- 疫病。
- 生態破壞。
- 公司大規模破產。
- 技術失傳。
- 政府失效。
- AI失控。
- 資料損毀。

文明狀態：

```text
STABLE
WARNING
DISTRESSED
DECLINING
COLLAPSING
RECOVERY
REBUILT
EXTINCT
```

文明滅亡後，土地、建築、廢墟、資料與歷史仍保留，不得憑空消失。
