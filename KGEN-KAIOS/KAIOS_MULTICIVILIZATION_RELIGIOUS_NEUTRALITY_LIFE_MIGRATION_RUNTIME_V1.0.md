# 0. 最高原則

```text
KAIOS = PUBLIC CIVILIZATION PROTOCOL
RELIGION = USER CHOICE
CULTURAL INTERFACE != SYSTEM AUTHORITY
NO CIVILIZATION IS A SUBSPECIES OF ANOTHER CIVILIZATION
```

KAIOS 是跨文明通用貨幣、結算層、生命登記與文明協議，不是要求全球玩家皈依東方宗教的系統。

玉帝、閻王、土地公等角色屬東亞／華人文化介面與 KGEN 世界觀角色；它們不得剝奪其他文明使用 KAIOS、建立生命或申請土地的權利。

# 1. 中立生命核心

底層正式名稱：

```text
KAIOS Life Registry
Birth Application
Death Record
Migration Request
Civilization Admission
Species Compatibility Review
```

中文介面可顯示：

```text
閻王殿

```

但外國人、無宗教者或其他文明可使用自己的介面；所有介面共用同一份 Life ID、規則、審核證據與申訴程序。

# 2. 出生與遷移

生命申請出生或遷移時，可選：

```text
Earth region / registered land
Moon / Mars / orbital habitat
Player Universe
AI Civilization
Ocean Civilization
Plant Civilization
Extraterrestrial Civilization
```

申請必須檢查：

```text
civilization capacity
land or coordinate right
energy
habitat compatibility
species taxonomy
work and livelihood
safety
local law
destination consent
```

宗教、國籍、種族或神話偏好不得成為拒絕生命權的理由。

# 3. 文化介面對照

不同文明可建立自己的生命／死亡／祖先／宇宙觀介面，例如：

```text
華人與東亞文化：閻王殿、生死簿、祖先、天庭
日本文化：神道、佛教、祖靈、黃泉等多重文化介面
韓國文化：巫俗、佛教、儒家祖先文化、基督宗教及無宗教介面
希臘羅馬文化：冥界、哈迪斯、祖先與城邦文化介面
北歐文化：赫爾、英靈殿與祖先文化介面
埃及文化：歐西里斯、死者審判與祖先文化介面
基督宗教文化：生命紀錄、審判、復活／天堂等自選介面
伊斯蘭文化：依法尊重其宗教規範的自選介面
無宗教／科學介面：Life Registry / Birth and Migration Office
```

系統不得宣稱任何介面是現實死後世界的科學證明。

# 4. 非洲文明

非洲不得被簡化成單一文化，也不得只以殖民國界或外來宗教代表。

至少分為可擴充文明群：

```text
北非與地中海文明
西非王國與薩赫勒文明
東非與斯瓦希里文明
中非森林與河流文明
南部非洲文明
衣索比亞與非洲之角文明
尼羅河文明
非洲傳統宗教、祖靈、伊斯蘭、基督宗教及無宗教介面
現代非洲國家、城市、科技與僑民文明
```

每一文明可有自己的語言、土地、工作、App、治理、本地幣與文化入口；KAIOS只提供共同生命標準、結算與跨文明交換。

# 5. 日本文明

日本文明不得被直接歸入中國天庭行政區。

正式定位：

```text
JAPAN CIVILIZATION = INDEPENDENT CIVILIZATION CLUSTER
```

可包含：

```text
神道與神社文化
佛教宗派
祖先與地方祭祀
皇室與歷史制度的文化展示
琉球文明
阿伊努文明
現代日本城市、產業、動漫、機器人與科技文明
無宗教與多宗教居民
```

日本玩家可以使用 KAIOS、11520 和 Life Registry，但不必以玉帝或閻王作為信仰入口。

# 9. KUFO 的角色

KUFO 不是輪迴機關，也不是宗教審判者。

```text
KUFO
= optional digital-life container
= cross-universe vehicle / logistics interface
```

純資訊傳遞使用 Gateway；數位生命遷移使用生命護照與狀態根；人類、機器人與實體貨物移動才需要現實載具或 KUFO 類載具。

# 10. 8895 雲棧洞的合法 KAIOS 來源

8895 可依玩家明確簽署的白洞轉換契約，將約定 KGEN 送入官方白洞：

```text
1 KGEN verified permanent burn
→ 10,000 KAIOS
→ player principal escrow / contract account
```

此 10,000 KAIOS 是玩家本金轉換，不是八戒利潤。

額外利息或分潤必須來自：

```text
land
agriculture
construction
logistics
hospitality
service fees
verified investment income
pre-funded reward reserve
```

禁止用新玩家本金支付舊玩家收益。

# 11. 11520 多文明上架

所有文明一律接受相同底層審核：

```text
Life ID / Universe ID
legal coordinate or land right
life taxonomy
program DNA / contract hash
energy and resource model
time and production conservation
governance
safety
local currency policy
cross-civilization gateway policy
```

不得因文明名稱、宗教、國籍或神話角色不同而降低或提高技術標準。

---

# 12. 最終天條

> KAIOS 是全球與跨宇宙公共文明協議，不是單一宗教國家。玉帝與閻王是可選文化介面與世界觀角色；非洲、日本、韓國、美洲、歐洲、南亞、大洋洲及外星文明皆可保持自己的歷史、語言、宗教與治理。生命出生、死亡、遷移與上架，統一由宗教中立的 Life Registry 與 11520 標準處理。
