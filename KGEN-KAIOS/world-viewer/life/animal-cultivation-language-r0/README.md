# KAIOS 萬獸修練語 R0｜獨立可測試候選

Human 2026-10-18 創作提議：KTRAIN 0–300 後知後決；301–3000 不知不覺；3001–30000 先知先決。KTRAIN 是遊戲修練值，**不是** K0 宇宙地圖 Point ID、KGEN 指數或真實動物智力。K3001 只是語意理解的高階資格；沒有實際 NLP、STT、訓練成功率證據不得說能聽懂自由人話。

本 R0 支援 8 個封閉意圖（FOLLOW/GUARD/HARD_FIGHT/ROAM/STAY/ALERT/FOOD/HELP）、繁中／英文／三國風格固定片語、K300 原 300 字字典編碼、跨物種共同意圖碼以及明確 receiver ACK；不提供真正語音、物種聲音分析、預知未來、金融下單或生命 ID。

**K5 判定**：既有 #596 先定義的火星五位數「兩位筆畫數＋三位同畫字序」語言，創意稱「火星機械文明語」。變形金剛角色可使用它，但它不是一種已證實的《變形金剛》官方語言。字典未定稿時拒絕轉譯；K300 是另一套已固定的 3 位數 300 字字典，不准覆寫。

**速度**：共享語意的八條指令只需 1 byte payload，未計 message ID/header/ACK/翻譯/傳輸延遲；這是小詞彙機器碼，不是世界上最快的自然語言，也不具超光速通訊。

同種或異種要有共同版本協定或已驗證翻譯器；獲得訊息後須由被指名的接收者 ACK，不能說『兩隻動物已交談成功』。對接原 #610 K6888 動物時由原 owner 另行驗收，**不能自動讓兩隻動物跨物種聽懂**。
