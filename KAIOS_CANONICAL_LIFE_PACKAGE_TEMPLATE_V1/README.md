# KAIOS Canonical Life Package Template V1

Copy this directory only in an authorized candidate workline. Replace every
`TEMPLATE_*` value, select the approved extension for the Life type, calculate
SHA-256 after all records are stable, and validate `life.manifest.json` against
`../KAIOS_CANONICAL_LIFE_SCHEMA_V1.json`.

The template is `CANDIDATE_ONLY`, `NON_EXECUTABLE_BINDING`,
`NO_PRODUCTION_AUTHORITY`, `NO_REAL_KGEN`, `NO_ONCHAIN_TRANSFER`, and
`SIMULATED_K11520_ONLY`. It creates no legal person, wallet, title or runtime.
