# K280 Security and Authority Boundaries

## Enabled

- deterministic local simulation
- static read-only API projections
- browser visualization
- bounded simulated reproduction and mutation
- simulated K11520 listing preview

## Disabled

- Production Runtime
- Runtime CURRENT modification
- Scheduler
- Cursor dispatch
- automatic external agent creation
- wallet creation or connection
- private-key or seed-phrase access
- real KGEN use or transfer
- K11520 settlement
- contract deployment or modification
- Genesis or Universe Law modification
- real-world biological experimentation
- legal-personhood or real-sentience claims

## Resource Limits

Population defaults to 100 and cannot exceed 500. Event history and memory are
bounded. The engine does not require network access. Reproduction stops at
capacity, and candidate species branches remain unvalidated until processed by
the Species pipeline.

## Data Boundary

Static APIs contain only public simulation data. They expose no credentials,
private keys, private user information, hidden governance data, or production
configuration.
