# KAIOS-RAPTOR-K280-001

`KAIOS-RAPTOR-K280-001` is the first K280 digital-organism MVP instance.

Its identity, genome, body systems, runtime state, lifecycle, habitat, event
history, and rights are represented by separate machine-readable records. The
IDs are valid only inside this digital simulation package.

The organism is a software simulation. It has no legal personhood, real-world
sentience claim, wallet, employment, biological body, or Production Runtime
authority.
