# K280 Digital Raptor Species

This package defines `SPECIES-KAIOS-K280-RAPTOR` using the shared KAIOS
Organism Manifest Schema V2 and the central taxonomy and species registries.

`runtime_binding.json` resolves the species program to the bounded K280
JavaScript simulation. Genome, body, cell, organ, behavior, memory, lifecycle,
reproduction, mutation, habitat, rights, energy, and civilization-affinity
records are kept as separate references.

All outputs are simulation-only. No file in this package grants production
authority, creates a wallet, transfers KGEN, or supplies real biological
engineering instructions.
