requests, feasibility review, dependency-ordered project planning, finite
resource execution, inspection, delivery, maintenance and accounting.

## Runtime Contract

The Runtime owns order coordination only. It implements structured requests,
visible assumptions, sixteen feasibility gates, nine project templates,
dependency graphs, resource plans, schedules, simulation-only contracts,
procurement, task execution, inspection, rework, change orders, delivery,
maintenance, finite company capacity and deterministic event replay.

It does not own or mutate Canonical Life, Universe Physics, Rights authority,
Economy authority, CURRENT, Constitution sources, Wallet, KGEN or Production
authority.
